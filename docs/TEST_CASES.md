# 理发店会员小程序测试用例文档

## 1. 文档目的

本文档用于指导小程序在上线前进行完整测试，覆盖功能正确性、角色权限、统计准确性、环境切换、日志可追溯性和上线回归。

## 2. 测试范围

- 店铺初始化与店铺资料
- 团队协作与角色权限
- 会员新增、编辑、删除
- 充值、消费、调账
- 到店登记、到店次数、最近到店时间、复购提醒
- 经营报表
- 跨店数据隔离
- 云函数调用日志与业务审计日志
- 测试 / 生产双环境切换

## 3. 测试环境

### 3.1 基础环境

- 小程序 `AppID`：`wx95d05dde35d863bb`
- 基础库版本：不低于 `3.4.7`
- 微信开发者工具：最新版稳定版
- 云函数依赖：`wx-server-sdk@3.0.4`

- `A-Staff`：A 店员工
- `B-Manager`：B 店店长

## 4. 测试准入条件

- 4 个云函数已部署成功：
  - `shopService`
  - `memberService`
  - `adjustBalance`
  - `reportService`
- 数据集合已创建：
  - `shops`
  - `shop_users`
  - `members`
  - `member_transactions`
  - `member_visits`
  - `function_logs`
  - `operation_audits`
- 数据库权限已按部署文档配置
- 索引已创建

## 5. 测试退出条件

- 所有 `P0`、`P1` 用例通过
- 无越权、串店、金额错误、报表错误
- 首页统计与报表统计抽样核对一致
- 环境切换与日志记录可正常使用

## 6. 测试数据准备

- A 店有效会员至少 60 个
- A 店交易流水至少 600 条
- A 店到店记录至少 600 条
- A 店至少 1 名员工
- B 店至少 1 名店长与独立会员数据

## 8. 抽样核对方法

### 8.1 首页概览核对

在数据库中按当前 `shopId` 手工统计：

- `members` 中 `status != deleted` 的数量
- `balance > 0` 的数量
- 有效会员余额总和

与首页概览逐项对比。

### 8.2 报表核对

在数据库中按时间段抽样统计：

- `member_transactions` 中 `recharge` 金额合计
- `member_transactions` 中 `consume` 金额合计
- `member_visits` 数量
- `members.createdAt` 落在时间段内的新增会员数

与报表页逐项对比。

### 8.3 日志核对

执行一次新增会员、一次调账、一次角色调整，确认：

- `function_logs` 至少新增对应调用记录
- `operation_audits` 至少新增对应业务记录
- 设置页能看到最近日志

## 9. 缺陷分级建议

- `P0`：无法建店、越权、串店、金额错误、报表错误、环境误连
- `P1`：关键页面不可用、日志缺失、排序筛选错误、关键空状态错误
- `P2`：样式错位、文案不统一、非关键交互异常
